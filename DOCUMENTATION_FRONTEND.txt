4. COMPOSANTS PRINCIPAUX
=========================

A. LOGIN (src/app/auth/login/)
─────────────────────────────

Fichier: login.ts
│
├── Classe: Login
│   ├── Properties:
│   │   ├── username: string = '' [Nom d'utilisateur]
│   │   ├── password: string = '' [Mot de passe]
│   │   ├── loading: boolean = false [État du chargement]
│   │   └── error: string | null = null [Messages d'erreur]
│   │
│   └── Méthodes:
│       ├── onLogin(): void
│       │   ├── Valide les inputs
│       │   ├── Appelle authService.login()
│       │   ├── Stocke le JWT
│       │   └── Navigue vers /dashboard
│       │
│       └── navigateToRegister(): void [Navigue vers /register]
│
├── Selector: app-login
├── Template: login.html (formulaire + error display)
└── Styles: login.scss (gradient background + formulaire)

FONCTIONNEMENT:
1. Utilisateur remplit username + password
2. Clique "Login"
3. onLogin() valide: username ET password remplis
4. this.loading = true (bouton désactivé)
5. authService.login() effectue POST /auth/login
6. Si succès: 
   - Token reçu et sauvegardé dans localStorage
   - Redirection vers /dashboard
7. Si erreur:
   - Message d'erreur affiché
   - loading = false (bouton réactivé)

✓ Mots de passe identiques

FLUX ENREGISTREMENT:
1. Remplit tous les champs
2. Clique "Register"
3. Validations côté client
4. POST /auth/register
5. Si succès:
   - Utilisateur créé en BD
   - Auto-login avec les mêmes identifiants
   - POST /auth/login
   - Token sauvegardé
   - Redirection /dashboard

5. SERVICES
===========

A. AuthService (src/app/services/auth.ts)
─────────────────────────────────────────

Gère TOUTE la communication HTTP avec le backend.

Interface:
│
├── Propriété privée:
│   └── apiUrl = 'http://localhost:8080/auth' [URL backend]
│
├── Méthodes principales:
│   │
│   ├── login(username: string, password: string)
│   │   ├── POST /auth/login
│   │   ├── Payload: { username, password }
│   │   ├── ResponseType: 'text' [IMPORTANT: retour plain text JWT]
│   │   └── Retourne: Observable<string> [Le JWT]
│   │
│   ├── register(username: string, email: string, password: string)
│   │   ├── POST /auth/register
│   │   ├── Payload: { username, email, password }
│   │   ├── ResponseType: 'json' (par défaut)
│   │   └── Retourne: Observable<any> [Objet User]
│   │
│   ├── saveToken(token: string): void
│   │   └── Appelle tokenService.setToken(token)
│   │
│   ├── logout(): void
│   │   ├── Appelle tokenService.removeToken()
│   │   └── Navigue vers /login
│   │
│   └── isAuthenticated(): boolean
│       └── Retourne tokenService.hasToken()

EXEMPLE D'UTILISATION DANS UN COMPOSANT:
```
this.authService.login(username, password).subscribe({
  next: (token) => {
    this.authService.saveToken(token);
    this.router.navigate(['/dashboard']);
  },
  error: (err) => {
    this.error = err.error?.message || 'Login failed';
  }
});
```

DÉTAILS TECHNIQUES:
- Utilise HttpClient de Angular
- Les requêtes utilisent POST
- Retourne un Observable (pattern RxJS)
- S'abonn avec .subscribe({ next: ..., error: ... })


B. TokenService (src/app/services/token.ts)
───────────────────────────────────────────

Gère le JWT dans localStorage du navigateur.

Interface:
│
├── Propriété privée:
│   └── TOKEN_KEY = 'jwt_token' [Clé localStorage]
│
├── Méthodes:
│   │
│   ├── setToken(token: string): void
│   │   └── localStorage.setItem('jwt_token', token)
│   │
│   ├── getToken(): string | null
│   │   └── Retourne localStorage.getItem('jwt_token') ou null
│   │
│   ├── hasToken(): boolean
│   │   └── Retourne !!this.getToken() [true si token existe]
│   │
│   ├── isTokenValid(): boolean
│   │   └── Retourne token existe ET n'est pas vide
│   │       (utilisé par authGuard)
│   │
│   └── removeToken(): void
│       └── localStorage.removeItem('jwt_token')

EXEMPLE D'UTILISATION:
```
// Sauvegarder
const token = 'eyJhbGciOiJIUzI1NiJ9...';
this.tokenService.setToken(token);

// Récupérer
const token = this.tokenService.getToken();

// Vérifier
if (this.tokenService.isTokenValid()) {
  // L'utilisateur est connecté
}

// Supprimer (logout)
this.tokenService.removeToken();
```

STOCKAGE:
- localStorage est persistant (reste après fermeture navigateur)
- Accessible uniquement depuis JavaScript (pas httpOnly)
- À protéger contre XSS en production


6. GUARDS (PROTECTION DE ROUTES)
=================================

Fichier: src/app/guards/auth-guard.ts

Guard Type: CanActivateFn (fonctionnel - approche moderne Angular)

FONCTION:
export const authGuard: CanActivateFn = (route, state) => {
  const tokenService = inject(TokenService);
  const router = inject(Router);

  // 1. Vérifie si token existe et est valide
  if (tokenService.isTokenValid()) {
    return true; // Accès autorisé
  }

  // 2. Token invalide - redirection
  router.navigate(['/login']);
  return false; // Accès refusé
};

UTILISATION DANS app.routes.ts:
```
{
  path: 'dashboard',
  component: Dashboard,
  canActivate: [authGuard]  // Guard appliqué à cette route
}
```

FLUX:
1. Utilisateur tente d'accéder à /dashboard
2. Angular exécute authGuard avant de charger le composant
3. Guard appelle tokenService.isTokenValid()
4. Si true: composant Dashboard chargé normalement
5. Si false: redirection vers /login, Dashboard pas affiché

A. app.routes.ts (Configuration des routes)
────────────────────────────────────────────

Définit le routage de l'application:

const routes: Routes = [
  { 
    path: '', 
    redirectTo: 'login', 
    pathMatch: 'full' 
  },
  { 
    path: 'login', 
    component: Login 
  },
  { 
    path: 'register', 
    component: Register 
  },
  { 
    path: 'dashboard', 
    component: Dashboard, 
    canActivate: [authGuard]  // PROTECTED!
  },
  { 
    path: '**', 
    redirectTo: 'login' 
  }
];

EXPLICATIONS:
- Accès '' → redirige vers /login
- /login: page de connexion (accès public)
- /register: page d'inscription (accès public)
- /dashboard: page protégée (nécessite authGuard + token valide)
- '**' (any): redirige vers /login (fallback)

D. Ajouter interceptor HTTP pour JWT
─────────────────────────────────────

EN PRODUCTION, inclure JWT dans CHAQUE requête:

Créer: src/app/interceptors/auth.interceptor.ts

```
import { HttpInterceptor, HttpRequest, HttpHandler, HttpEvent } from '@angular/common/http';
import { Observable } from 'rxjs';

export class AuthInterceptor implements HttpInterceptor {
  constructor(private tokenService: TokenService) {}

  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    const token = this.tokenService.getToken();
    
    if (token) {
      req = req.clone({
        setHeaders: {
          Authorization: `Bearer ${token}`
        }
      });
    }
    
    return next.handle(req);
  }
}
```

Puis enregistrer dans app.config.ts:
```
provideHttpClient(
  withInterceptors([authInterceptor])
)
```

COMMON ERRORS ET SOLUTIONS
===========================

ERREUR: "Cannot find module 'auth.ts'"
SOLUTION: Vérifier les imports
  import { AuthService } from '../../services/auth';

ERREUR: "Type 'Observable' requires 1 type argument"
SOLUTION: Observable<type>
  Observable<string> ou Observable<any>

ERREUR: "RouterLink not used in template"
SOLUTION: Ou ajouter routerLink dans HTML, ou supprimer import

ERREUR: CORS error 401 / 403
SOLUTION: Vérifier backend CORS config (SecurityConfig.java)

ERREUR: "Cannot read property 'setItem' of undefined"
SOLUTION: localStorage pas disponible (check SSR context)

ERREUR: Token jamais décodé / utilisé
SOLUTION: Ajouter interceptor pour inclure dans chaque requête
