## 🚀 Comment Ça Marche

### 1️⃣ BUILD (première fois - ~3 min)
```bash
docker-compose up --build
```
- Compile le backend (Maven)
- Compile le frontend (Angular/Webpack)
- Crée les images Docker
- Démarre les 3 services

### 2️⃣ WAIT (~20 secondes)
- Healthchecks assurent que tous les services sont prêts
- Backend attend que la BD soit accessible
- Frontend attend que le backend soit prêt

### 3️⃣ READY
```
Frontend:  http://localhost:4200  ✅
Backend:   http://localhost:8080  ✅
Database:  postgresql://localhost:5432 ✅
```

## 🐛 Troubleshooting

### "Docker not found"
→ Installer Docker Desktop

### "Port 4200 already in use"
→ Changer port dans docker-compose.yml ou kill le processus

### "Cannot connect to database"
→ Attendre ~10 sec, les healthchecks confirment quand c'est prêt

### "Frontend shows blank page"
→ Vérifier logs: `docker-compose logs frontend`
→ Rebuild: `docker-compose down -v && docker-compose up --build`

### "Backend 500 error"
→ Vérifier logs: `docker-compose logs backend`
→ Vérifier variables d'env
