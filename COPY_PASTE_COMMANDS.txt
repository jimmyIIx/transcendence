🚀 COMMANDES À COPIER-COLLER
============================

## ✅ PREMIÈRE FOIS (Build + Start)

```bash
cd c:\Users\arthu\OneDrive\Bureau\transcendence
docker-compose up --build
```

Attendre 2-3 minutes le temps que les images se buildent.

Vous verrez:
```
transcendence-frontend | Nginx is running...
transcendence-backend  | Started TranscendenceApplication
transcendence-db       | database system is ready to accept connections
```

## ✅ VÉRIFIER QUE TOUT MARCHE

## ✅ VOIR LES LOGS

```bash

docker-compose logs -f

# Backend seulement

# Frontend seulement
docker-compose logs -f frontend

# Database seulement
docker-compose logs -f db
```

## ✅ SI CA NE MARCHE PAS

### "docker: command not found"
Installer: https://www.docker.com/products/docker-desktop

### "Port 4200 already in use"
```bash
# Option 1: Trouver et tuer
lsof -i :4200
kill -9 <PID>

# Option 2: Utiliser un autre port
# Éditer docker-compose.yml:
# ports: ["8000:4200"]  # Puis accéder à http://localhost:8000
```

### "Cannot connect to database"
Attendre 10 secondes, les healthchecks confirment quand c'est prêt.

### Le frontend affiche une page blanche
```bash
docker-compose logs frontend
# Puis rebuild:
docker-compose down -v
docker-compose up --build
```
