1. VUE D'ENSEMBLE DU PROJET
============================

Transcendence est une application web de paris sportifs complète composée de:
- Un BACKEND: API REST Spring Boot (Java) pour la gestion d'authentification et des données
- Un FRONTEND: Application Angular 18+ avec SSR pour l'interface utilisateur
- Une BASE DE DONNÉES: (à configurer - actuellement en dev)

Le projet implémente un système d'authentification JWT sécurisé avec:
✓ Inscription d'utilisateurs
✓ Connexion avec JWT
✓ Protection des routes
✓ Gestion des tokens
✓ Interface utilisateur responsive

5. FLUX D'AUTHENTIFICATION
============================

DIAGRAMME DU FLUX:

┌──────────────────────────────────────────────────────────────────┐
│ INSCRIPTION (Register)                                          │
│ ─────────────────────────────────────────────────────────────── │
│                                                                  │
│ 1. Utilisateur remplit le formulaire                           │
│    - Username (nom d'utilisateur)                             │
│    - Email (adresse email)                                    │
│    - Password (mot de passe, min 6 caractères)              │
│    - Confirm Password (confirmation)                         │
│                                                                │
│ 2. Frontend valide (côté client):                            │
│    ✓ Tous les champs sont remplis                           │
│    ✓ Les mots de passe correspondent                        │
│    ✓ Password >= 6 caractères                               │
│                                                                │
│ 3. POST /auth/register                                       │
│    {                                                          │
│      "username": "Djomino06",                               │
│      "email": "user@example.com",                           │
│      "password": "password123"                              │
│    }                                                          │
│                                                                │
│ 4. Backend (AuthController):                                │
│    ✓ Valide les données                                     │
│    ✓ Crée l'utilisateur en BD                               │
│    ✓ Hash le mot de passe (BCrypt)                          │
│    ✓ Retourne l'objet User                                  │
│                                                                │
│ 5. Frontend auto-login (appelle login avec les même identifiants)
│                                                                │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ CONNEXION (Login)                                               │
│ ─────────────────────────────────────────────────────────────── │
│                                                                  │
│ 1. Utilisateur remplit le formulaire                           │
│    - Username (nom d'utilisateur)                             │
│    - Password (mot de passe)                                  │
│                                                                │
│ 2. Frontend valide (côté client):                            │
│    ✓ Tous les champs sont remplis                           │
│                                                                │
│ 3. POST /auth/login                                         │
│    {                                                          │
│      "username": "Djomino06",                               │
│      "password": "password123"                              │
│    }                                                          │
│                                                                │
│ 4. Backend (AuthController):                                │
│    ✓ Vérifie les identifiants                               │
│    ✓ Génère JWT avec JwtUtils.generateToken(username)       │
│    ✓ Retourne le JWT (plain text)                           │
│      eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJEam9taW5vMDYi...       │
│                                                                │
│ 5. Frontend reçoit le JWT:                                  │
│    ✓ Stocke dans localStorage (clé: "jwt_token")            │
│    ✓ Navigue vers /dashboard                                │
│                                                                │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│ PROTECTION DES ROUTES                                           │
│ ─────────────────────────────────────────────────────────────── │
│                                                                  │
│ Quand utilisateur accède à /dashboard:                        │
│                                                                │
│ 1. Angular authGuard vérifie:                               │
│    ✓ TokenService.isTokenValid()                            │
│      - Récupère token de localStorage                      │
│      - Vérifie qu'il existe et n'est pas vide              │
│                                                                │
│ 2. Si token valide:                                         │
│    ✓ Accès autorisé → affiche dashboard                     │
│                                                                │
│ 3. Si token invalide/absent:                               │
│    ✓ Redirection automatique vers /login                    │
│    ✓ Utilisateur doit se reconnecter                       │
│                                                                │
│ 4. Au logout:                                              │
│    ✓ TokenService.removeToken() supprime du localStorage    │
│    ✓ Navigue vers /login                                    │
│                                                                │
└──────────────────────────────────────────────────────────────────┘

ENDPOINTS API BACKEND:
======================

POST /auth/login
────────────────
Request:
{
  "username": "Djomino06",
  "password": "password123"
}

Response: 
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJEam9taW5vMDYiLCJpYXQiOjE2OTgyNDU...
(Plain text JWT token)

POST /auth/register
───────────────────
Request:
{
  "username": "Djomino06",
  "email": "djomino@example.com",
  "password": "password123"
}

Response:
{
  "id": 1,
  "username": "Djomino06",
  "email": "djomino@example.com",
  "createdAt": "2026-04-19T19:00:00Z"
}

6. ÉTAPES D'INSTALLATION ET DÉMARRAGE
======================================

PRÉREQUIS:
──────────
- Git installé
- Node.js v18+ installé
- Java 17+ installé
- Maven 3.8+ installé
- MySQL ou PostgreSQL (configuration recommandée)

INSTALLATION DU FRONTEND (Angular):
────────────────────────────────────

1. Naviguer dans le dossier frontend:
   cd 42bets-frontend

2. Installer les dépendances:
   npm install

3. Vérifier que le backend est déjà configuré

4. Démarrer le serveur de développement:
   ng serve
   ou
   npm start

5. Accéder à http://localhost:4200

INSTALLATION DU BACKEND (Spring Boot):
───────────────────────────────────────

1. Naviguer dans le dossier backend:
   cd transcendence

2. Configurer application.properties:
   Éditer: src/main/resources/application.properties
   - Port: server.port=8080
   - Base de données: spring.datasource.url, username, password
   - Autres configurations Spring

3. Compiler et démarrer:
   ./mvnw spring-boot:run
   ou
   mvn clean install
   java -jar target/transcendence-0.0.1-SNAPSHOT.jar

4. Backend accessible sur http://localhost:8080

5. Vérifier la configuration CORS dans:
   src/main/java/com/ft/transcendence/security/SecurityConfig.java
   - Doit permettre http://localhost:4200


DÉMARRAGE COMPLET:
──────────────────

Terminal 1 (Backend - Java):
  cd transcendence
  ./mvnw spring-boot:run

Terminal 2 (Frontend - Angular):
  cd 42bets-frontend
  ng serve

Terminal 3 (Navigation):
  Ouvrir http://localhost:4200 dans le navigateur


TESTER L'APPLICATION:
─────────────────────

1. Accéder à http://localhost:4200/register
2. Créer un compte (username, email, password)
3. Remplir le formulaire et cliquer "Register"
4. Auto-login et redirection vers /dashboard
5. Cliquer "Logout" pour se déconnecter
6. Essayer d'accéder à /dashboard → redirection /login
7. Cliquer sur "Login here" pour retourner à /login
8. Se connecter avec les identifiants créés
9. Accès au dashboard réussi!

NOTES IMPORTANTES:
===================

1. LE JWT EST STOCKÉ EN CLAIR DANS LOCALSTORAGE:
   - Acceptable pour dev/test
   - En production: utiliser httpOnly cookies + CSRF protection
   - Évite XSS attacks

2. CORS CONFIGURÉ POUR DEV:
   - Actuellement: permettre http://localhost:4200
   - En production: configurer domain spécifique
   - Vérifier SecurityConfig.java

3. RÉPONSE LOGIN EST EN PLAIN TEXT:
   - Backend retourne le token brut (pas de JSON wrapper)
   - Frontend configure responseType: 'text' dans HttpClient.post()

4. MODULE RESOLUTION BUNDLER:
   - Changé de NodeNext pour compatibilité SSR
   - module: ES2022 pour modules ES modernes

5. DEBUGGUER:
   - Ouvrir DevTools (F12)
   - Console: voir les logs de debug
   - Network: voir les requêtes HTTP/réponses
   - Application: voir localStorage avec jwt_token
